# Images & PDFs

- `og-default.png` — default 1200x630 social preview. Add it here before going public.
- `resume.pdf` — the downloadable resume PDF. Generate from `/resume` (Print → Save as PDF) or export your master resume here.
- `blog/` — per-article cover images (1200x630). Reference them in frontmatter as `coverImage: /images/blog/my-post.png`.
- `projects/` — project diagrams/screenshots.

Keep images compressed (WebP/JPEG) and sized to max 1200px wide for fast loading.
