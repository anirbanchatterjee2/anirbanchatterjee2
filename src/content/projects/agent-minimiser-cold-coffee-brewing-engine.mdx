## Problem statement

Agentic workflows waste tokens: redundant reasoning, oversized context, verbose tool outputs, and unfocused planning loops. The cost and latency compound with every step.

## Motivation

Treat tokens as a scarce resource. Can we minimise work per task without losing quality — brewing the result hot, not cold?

## Architecture (concept)

- **Budget layer:** Per-task token / step budgets with explicit stop conditions.
- **Context pruning:** Summarise and compact history; pass only task-relevant state to each node.
- **Tool output shaping:** Truncate and structure tool results before they enter the model context.
- **Routing:** Cheap model for triage / classification, capable model only where reasoning depth is needed.
- **Evaluation:** Measure task success vs. token cost so efficiency gains are provable, not vibes.

## Challenges

- Aggressive minimisation can break multi-step reasoning.
- Evaluation needs representative tasks, not cherry-picked demos.
- No production numbers claimed — this is a research concept at the time of writing.

## Current status

Concept / Research — early design, no production deployment.
